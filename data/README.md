# Data boundary

Only fictional sample data belongs in this directory's tracked files.

Store real Google Form exports and downloaded classmate photographs under `data/private/`. That directory is excluded by `.gitignore` and must never be committed to the public repository.

Expected private layout:

```text
data/private/
├── approved_profiles.csv
└── photos/
    ├── submitted_photo_01.jpg
    └── submitted_photo_02.png
```
